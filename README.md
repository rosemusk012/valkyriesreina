# Valkyries Reina

A calm, sovereign portfolio for the **Valkyries Reina** brand — dark ink, ivory type, brass accents.

Built with **Vite + React + TypeScript + Tailwind CSS**. Single-page layout with anchor sections.

## Quick start

From the project root:

1. Install dependencies (`bun install` or the Node package manager)
2. `bun run dev` — listens on 0.0.0.0:5173
3. `bun run build` then `bun run preview` — listens on 0.0.0.0:4173

## Edit creations

All gallery items live in `src/data/creations.ts`.

## Sections

1. Hero — brand and tagline
2. Creations — Grok, Lovable, Manus, Meta AI
3. Support — FundRazr featured; Shopify coming soon
